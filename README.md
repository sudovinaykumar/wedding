# Rachana & Vinay — Wedding Invitation

GitHub Pages-ready wedding invitation.

## Files
- `index.html` — main invitation page
- `opening.png` — opening screen
- `page1.png` — invitation page 1
- `page2.png` — wedding ceremony, reception and location
- `page3.png` — closing page

## Features
- Opening screen with **TAP ANYWHERE** guidance
- Full-screen page-by-page scrolling with snap behavior
- Smooth small-to-big page artwork entrance effect
- Matching rounded/capsule **SCROLL DOWN** guidance on pages 1 and 2
- Guidance reappears when returning to a page
- Transparent Google Maps hit area over **View Location** on page 2
- Mobile-friendly and desktop-friendly layout

## GitHub Pages
Upload all files to the repository root and enable GitHub Pages from the repository's Pages settings.
